# ADR-0007. Бронирование подтверждается асинхронно: 202 + очередь + worker

**Статус:** принято (с версии 0.1.0)

## Контекст
Подтверждение бронирования в настоящем отеле — долгий и ненадёжный шаг: проверки, обращение к внешней системе отеля, платёж. В демо это имитируется паузами 0,7–0,9 с на каждом шаге.

## Проблема
Наивная версия делает всё прямо в HTTP-запросе: проверила, подтвердила, ответила. Тогда:
- пользователь ждёт секунды, и при всплеске запросов сервер держит тысячи «висящих» соединений;
- если внешняя система упала, падает и запрос пользователя, хотя бронирование можно было бы подтвердить через минуту;
- если сервер перезапустился посреди обработки, никто не знает, на каком шаге она остановилась.

## Решение
Асинхронная обработка [[61]](glossary.md#t61):
1. API проверяет данные, сохраняет бронирование со статусом `pending` и отвечает **202** [[27]](glossary.md#t27) за миллисекунды.
2. Задача уходит в RabbitMQ через outbox (ADR-0002).
3. Worker [[25]](glossary.md#t25) забирает задачу и переводит бронирование в `confirmed` или `rejected`.
4. Фронтенд опрашивает `GET /api/bookings/{id}` и показывает таймлайн.

Комната закрепляется за гостем **сразу**, ещё в статусе `pending` (ADR-0001), поэтому, пока идёт подтверждение, продать её второй раз нельзя.

## Альтернативы
- **Всё синхронно** — проблемы описаны выше.
- **Фоновая задача в памяти API** (без брокера) — проще, но при перезапуске задача теряется, а масштабировать worker'ы отдельно от API нельзя.

## Последствия
- API отвечает быстро при любой нагрузке. Worker'ов можно запустить столько, сколько нужно [[49]](glossary.md#t49).
- Появляются статусы и их переходы, поэтому их правила вынесены в одно место и покрыты тестами.
- Фронтенду нужно опрашивать статус. Push через WebSocket — возможное улучшение.

## Коротко, своими словами
> «Долгую и ненадёжную работу не делаем, пока пользователь ждёт. Записали, ответили 202, worker доделает. Комната закрепляется сразу, так что асинхронность не открывает дыру для двойной продажи.»

- Laravel: `app/Http/Controllers/BookingController.php`, `app/Domain/BookingProcessor.php`
