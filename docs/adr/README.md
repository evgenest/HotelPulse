# Архитектурные решения (ADR)

**ADR — Architecture Decision Record.** Это короткий документ про одно архитектурное решение: какая была ситуация, какую проблему решали, что выбрали, какие варианты отбросили и чем за это платим. ADR не переписывают задним числом. Если решение меняется, пишут новый ADR со статусом «заменяет ADR-NNNN».

Шаблон: **Контекст → Проблема → Решение → Рассмотренные альтернативы → Последствия → Как объяснить на собеседовании.**
